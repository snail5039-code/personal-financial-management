# 자동 아침 브리핑 설정

## 가장 중요한 것

**설정을 바꿔도 트레이 앱이 실행 중이 아니면 알림은 오지 않는다.**

브리핑 알림을 실제로 보내는 건 이 대화창이 아니라 백그라운드 트레이 앱(KurimaTray)이다.
`set_briefing_time` / `set_briefing_enabled`는 "몇 시에, 켤지 말지"만 파일에 기록한다.

그래서 설정을 바꾼 뒤에는 **매번** 이 사실을 한 줄로 알려준다. 사용자가 시각만 바꿔놓고
알림을 기다리다 안 와서 고장으로 오해하는 게 이 기능에서 제일 흔한 문제다.

## 절차

1. **지금 설정을 먼저 본다.** `get_briefing_schedule`로 현재 시각과 켜짐 여부를 확인한다.
   사용자가 "브리핑 몇 시야?"라고만 물으면 여기서 끝낸다.

2. **바꾼다.**
   - 시각 변경: `set_briefing_time`
   - 켜기/끄기: `set_briefing_enabled`
   - 일정 알림 관련이면 `set_meeting_reminder_minutes` / `set_meeting_reminder_enabled`

3. **결과를 알린다.** 바뀐 값 + 위의 "트레이 앱이 켜져 있어야 한다"는 안내를 함께.

## 주의

- 사용자가 "브리핑 지금 보여줘"라고 하면 이 스킬이 아니다. 설정과 무관하게 그냥
  날씨·환율·뉴스·일정 도구를 직접 불러서 지금 화면에 보여주면 된다.
