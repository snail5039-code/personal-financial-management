# 회의·약속 준비

일정 하나를 골라서, 그 일정과 관련된 맥락(메일·메모·할일)을 모아 "뭘 챙겨야 하는지"까지
정리해준다.

## 절차

### 1단계 — 어떤 일정인지 특정한다

`calendar_search(start_date, end_date)`로 해당 기간을 조회한다. "내일"이면 내일 하루,
"다음 회의"면 오늘부터 7일 정도를 본다.

- 후보가 **하나면** 그걸로 진행한다.
- 후보가 **여러 개면** 임의로 고르지 말고 짧게 나열해서 사용자가 고르게 한다.
- 일정이 **없으면** 없다고 말한다. 지어내지 않는다.

### 2단계 — 무엇을 준비해야 하는 자리인지 판단한다

일정 제목만 봐도 성격이 대체로 드러난다. 성격에 따라 챙길 것이 다르다.

| 어떤 자리 | 챙길 것 |
| --- | --- |
| 업무 회의·미팅 | 지난 논의 내용, 내가 답해야 할 것, 공유할 자료, 결정이 필요한 사항 |
| 발표·면접 | 자료 최종본 위치, 예상 질문, 도착 시각과 이동 시간 |
| 병원·관공서 | 준비 서류, 예약 번호, 신분증, 시간 여유 |
| 약속·모임 | 장소, 만나는 사람, 지난번에 이야기한 것, 준비물(선물 등) |

성격이 애매하면 사용자에게 한 줄로 물어본다. 엉뚱한 걸 준비하게 하는 것보다 낫다.

### 3단계 — 맥락을 모은다

일정 제목과 참석자에서 뽑은 키워드로 찾는다.

- `email_search(query=...)` — Gmail 검색 문법을 쓴다. 참석자 메일 주소를 알면
  `from:주소` 로 좁히는 게 제목 검색보다 정확하다. 중요해 보이는 것만 `email_read`로 열어본다.
- `memo_search(query=...)` — 이전에 적어둔 메모가 있으면 가장 쓸모 있는 맥락이다.
- `todo_search(query=...)` — 이 일정과 관련된 미완료 할일이 있는지 본다.

세 가지가 다 비어 있어도 괜찮다. 그러면 "따로 남아 있는 기록은 없다"고 말하고 2단계의
체크리스트만 준다.

### 4단계 — 정리해서 준다

이 순서로:

1. **언제 · 어디서 · 누구와** (일정 정보 그대로)
2. **관련해서 찾은 것** — 메일/메모/할일에서 나온 것만. 없으면 없다고 한 줄.
3. **챙길 것 체크리스트** — 2단계 표를 그대로 붙이지 말고, 이 일정에 맞게 3~5개로 추린다.

### 5단계 — 준비물을 할일로 남긴다

체크리스트에서 실제로 해야 할 것이 있으면 `todo_registration(title, due=일정 날짜)`으로
등록할지 물어본다. 회의가 끝난 뒤 사용자가 결과를 알려주면, 그때 나온 액션 아이템도 같은
방식으로 등록한다.

## 주의

- **캘린더는 조회와 추가만 된다.** 일정 수정·삭제는 지원하지 않으므로, 시간을 바꿔달라고 하면
  "구글 캘린더에서 직접 바꿔야 한다"고 알려준다.
- 이동 시간이 필요한 자리면 출발 시각을 짚어준다. 다만 실제 소요 시간은 알 수 없으니
  단정하지 말고 "이동 시간 확인해두세요" 정도로 말한다.
- 여러 일정을 한 번에 준비해달라고 하면, 가장 빠른 것 하나를 먼저 끝내고 다음으로 넘어간다.
